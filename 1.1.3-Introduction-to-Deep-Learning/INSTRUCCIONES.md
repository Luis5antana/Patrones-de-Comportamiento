## Objetivo

Introducción al aprendizaje profundo: entrenar y comparar tres tipos de redes neuronales sobre el conjunto de datos MNIST.

## Paso a paso

1. Carga el conjunto de datos **MNIST, con 70,000 imágenes** en total.
2. Implementa un modelo **MLP** (perceptrón multicapa).
3. Implementa un modelo **CNN** (red neuronal convolucional).
4. Implementa un modelo **RNN** (red neuronal recurrente).
5. Entrena cada uno de los tres modelos durante **3 épocas**.
6. Compara el desempeño de MLP, CNN y RNN con el mismo protocolo de entrenamiento.
7. Concentra la comparación en el script `benchmark_redes.py`.

## Archivos y parámetros clave

- `benchmark_redes.py`: script principal con el benchmark de las tres redes.
- Dataset: MNIST, 70,000 imágenes.
- Modelos: MLP, CNN y RNN.
- Entrenamiento: 3 épocas por modelo.

## Entregables

- El código de los tres modelos (MLP, CNN, RNN).
- El archivo `benchmark_redes.py` con la comparación.
- Los resultados del entrenamiento y la comparación entre los tres modelos.
