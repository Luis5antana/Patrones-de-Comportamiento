## Objetivo

Comparar arquitecturas de redes neuronales con el conjunto de datos MNIST y poner a prueba el modelo con escritura propia y con ejemplos adversariales.

## Paso a paso

1. Compara las arquitecturas de red sobre MNIST con el script `benchmark_networks.py`.
2. Registra los resultados de cada arquitectura en la comparación.
3. Prueba el modelo entrenado con tu propia escritura a mano usando `test_my_handwriting.py`.
4. Ejecuta la prueba adversarial con `adversarial_test.py` para ver cómo se comporta el modelo ante ejemplos adversariales.
5. Reúne los resultados de las tres pruebas (comparación, escritura propia y prueba adversarial) en la entrega.

## Archivos y parámetros clave

- `benchmark_networks.py`: comparación de arquitecturas sobre MNIST.
- `test_my_handwriting.py`: prueba del modelo con escritura propia.
- `adversarial_test.py`: prueba adversarial del modelo.
- Dataset: MNIST.

## Entregables
